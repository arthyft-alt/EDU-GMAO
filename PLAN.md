## Contexte

| Sujet | Réponse |
|---|---|
| Élèves BTS MS | environ 15 |
| Administrateurs | 2 ou 3 enseignants |
| Ateliers | les 8 de l'annexe C, tels quels |
| Machines | environ 200, pas de liste existante : saisie dans l'application |
| Appareils | tablettes, téléphones personnels, PC fixes |
| Wi-Fi | oui, dans l'atelier |
| Comptes opérateurs | un seul compte opérateur partagé ; l'opérateur choisit son atelier sur l'appareil (mémorisé) et saisit son nom dans le BI |
| Matériel | douchette code-barres + imprimante d'étiquettes (modèles à préciser au module Stock / QR codes) |
| Hébergeur | **o2switch** (cPanel) dans un premier temps ; susceptible de changer plus tard |
| Adresse du site | https://gmaobrisson.fr (domaine de Simon chez o2switch) ; Python 3.12 sur le serveur |
